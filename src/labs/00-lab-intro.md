# 1부 · 실습 (2일 핸즈온)

> 구성주의 원칙 — 각 실습은 `🎯 목표 → ⌨️ 해보기 → 👀 보이는 것 → 💡 느낄 것` 순.
> 개념을 먼저 가르치지 않는다. **겪은 뒤 "아 이런거구나".** 왜 그런지는 → **2부 심화**.

## 읽는 법 / 전제
- 모든 VM은 **사전 프로비저닝**(이미지 pull 완료, 전원 off). 참가자는 켜서 복붙만.
- `⌨️` 블록은 **복붙용**. `⟨…⟩`는 환경 종속 값(강사가 실제 값으로 치환).
- 막히면 교육용 LLM에게 물어보며 진행.
- `💡 느낄 것` = 이 실습의 "아하" 지점. 강사는 유도만 하고 답을 미리 말하지 않는다.

> 각 실습 끝의 **📖 더 깊이** 링크로 2부 이론과 오간다. 커맨드만 빠르게 보려면 → **부록 D. 명령어 치트시트**.
