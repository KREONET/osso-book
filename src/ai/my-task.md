# 우리 환경 과제 {#my-task}

교재의 실습은 모두가 같은 랩 VM에서 합니다. 이 프롬프트는 배운 것을 **우리 연구실·기관의 실제 상황**으로 옮긴 작은 과제를 만들어 줍니다. 연습용 문제보다 실제에 가까운 문제가 훨씬 오래 기억에 남습니다.

```text
나는 ⟨출연연 연구실에서 GPU 서버 3대와 JupyterHub를 운영⟩한다.
방금 OSSO 교재의 ⟨⑨′ 컨테이너 egress 가두기⟩(src/labs/⟨lab-09p⟩.md)를 배웠다.

이걸 우리 환경에 써먹는, 단순하지만 진짜에 가까운 미니 과제 하나를 만들어 줘.
- 1시간 안에 끝나는 크기로
- 운영 서버가 아니라 테스트 VM이나 복제본에서 할 수 있게
- 시작 상태, 목표, 완료 기준(무엇을 보면 성공인지)을 분명히
- 정답 절차는 쓰지 마라. 대신 힌트를 3단계(방향 → 도구 → 거의 답)로 만들어
  내가 요청할 때 한 단계씩만 보여 줘라.
- 우리 환경에 대해 모르는 게 있으면 지어내지 말고 나에게 물어라.

과제는 my/task-⟨주제⟩.md에 저장하라.
```

## 예 {#my-task-example}

- ⑥ egress를 배운 뒤 → "우리 GPU 서버가 지난주에 접속한 외부 도메인 목록을 뽑고, 그중 꼭 필요한 것만 남긴 허용목록 초안 만들기"
- ⑩ 인증서를 배운 뒤 → "부서 위키에 붙어 있는 자체서명 인증서를 테스트 VM에서 DNS-01 인증서로 바꿔 보기"
- ⑨ + 부록 C를 배운 뒤 → "지금 엑셀로 관리하는 장비 목록을 오픈소스 도구로 옮길지 말지, ADR 한 장으로 결정하기"
