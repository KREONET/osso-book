# AI로 내 교재 만들기 {#ai}

이 책은 **원본**입니다. 여러분은 AI를 이용해 이 책을 **내 상황에 맞는 형태**로 바꿔 쓸 수 있습니다. 내 서버에 맞춘 경로, 차에서 들을 오디오, 휴대전화로 1분씩 보는 카드, 우리 연구실 상황에 맞춘 과제 등입니다.

## 시작하는 두 가지 방법 {#ai-start}

**① 저장소를 클론해서 (권장)**

```bash
git clone https://github.com/KREONET/osso-book
cd osso-book
# 또는 쓰는 AI 코딩 도구 아무거나
claude
```

저장소 맨 위의 `AGENTS.md`(Claude Code는 `CLAUDE.md`)에 이 책의 구조와 규칙이 적혀 있어서, AI가 이를 스스로 읽고 시작합니다. 만든 결과물은 `my/` 폴더에 저장되며 git에는 올라가지 않습니다.

**② 클론 없이**

AI 채팅창에 아래 프롬프트를 붙이고, 책을 함께 넘겨 주세요.

- 책 전체를 한 페이지로: <https://kreonet.github.io/osso-book/print.html>
- AI용 목차(원문 마크다운 링크): <https://kreonet.github.io/osso-book/llms.txt>

## AI를 쓸 때 지킬 세 가지 {#ai-rules}

AI가 내 생각을 **대신** 하게 두면 금방 편해지지만 남는 것이 없습니다. 그래서 프롬프트마다 이런 장치를 넣어 두었습니다.

1. **경로는 내가 고른다.** AI가 짜 준 로드맵을 그대로 따라가면 결국 남이 정한 수업을 다시 듣는 것과 같습니다. AI에게서는 **후보**만 받고, 고르는 일은 내가 합니다.
2. **예측과 설명은 내가 먼저 한다.** 명령을 실행하기 전에 결과를 먼저 예측하고, 💡를 보기 전에 내 해석을 먼저 말합니다. AI는 그다음에 내 생각의 **버그**를 찾아 줍니다.
3. **실제 운영 서버에서는 하지 않는다.** 실습 명령은 실습용 VM에서만 실행합니다. AI가 만든 명령도 마찬가지입니다.

> AI가 바꿔 준 결과물에도 틀린 내용이 섞일 수 있습니다. 이상하면 원본(이 책)과 대조하세요.
